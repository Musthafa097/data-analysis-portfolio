# Data Analysis Portfolio

Hi, I’m Muhammad Musthafa, an MSc Data Science graduate building projects in data analysis, Python, SQL, and machine learning. This repository contains practical projects that explore data, build models, and communicate findings clearly.

## Projects

| Project | Summary | Tools |
|---|---|---|
| [British Airways Customer Booking Prediction](British%20Airways%20Customer%20Booking%20Prediction/) | Predicts whether a customer completes a booking; includes model evaluation and a one-slide summary. | Python, pandas, scikit-learn, Jupyter Notebook |
| [Cricket Score Prediction](Cricket%20Score%20Prediction/) | Estimates an IPL first-innings score from the teams and match situation, and compares several regression models. See the project README for data requirements and limitations. | See project folder |
| [New York Taxi Trips Analysis](New%20York%20Taxi%20Trips%20Analysis/) | Cleans and analyses 6,400+ New York taxi trips to find when taxis are busiest, what drives the fare and who tips the most. | Python, pandas, NumPy, matplotlib, seaborn, Jupyter Notebook |

## About this portfolio

Projects are learning and portfolio work. Each project README describes the data, method, results, and limitations. Data files are excluded where sharing permission is unclear.
